# Data Cleaning & Visualization Project

**Goal:** Clean a raw dataset, process it, and visualize insights using Python (Pandas, Matplotlib, Seaborn).

## Dataset
`data/raw_sales_data.csv` – 1,260 e-commerce orders (order date, customer age, region, category, unit price,
quantity, discount, payment method, rating). The data is intentionally messy (generated by `make_raw_data.py`).

## Data problems found and how they were handled
| Problem | Count | Fix |
|---|---|---|
| Duplicate rows | 60 | Removed with `drop_duplicates()` |
| Inconsistent text (`NORTH`, ` north `, `upi`) | many | Strip spaces + Title Case (UPI restored) |
| Price stored as text with `$` | ~10% | Removed `$`, converted to float |
| Mixed date formats (`YYYY-MM-DD` and `DD/MM/YYYY`) | ~12% | Parsed both formats into one datetime column |
| Impossible values (age 150/999/-5, quantity -3/50/100) | 22 | Marked as NaN, then imputed |
| Missing values (age, region, price, payment, rating) | 325 | Median for numbers (price: median per category), mode for categories |
| Price outliers (5,000–20,000 for cheap items) | 12 | IQR rule per category, capped (winsorized) |

Result: **1,200 clean rows, 0 missing values** → `data/cleaned_sales_data.csv`.

## Visualizations (`charts/`)
Dashboard (`00_dashboard.png`), outliers before/after, missing values, monthly revenue trend, revenue by category,
region × category heatmap, age & rating distributions, payment share, correlation matrix.

## Key insights
- Electronics generates ~60% of total revenue.
- South is the top region; July 2025 is the peak month.
- Credit Card is the most used payment method.
- Average customer age ≈ 35; average rating ≈ 3.8 / 5.

## How to run
```bash

python data_cleaning_visualization.py   # cleans data + creates charts
```
Or open `Task1_Data_Cleaning_Visualization.ipynb` in Jupyter / Google Colab.
